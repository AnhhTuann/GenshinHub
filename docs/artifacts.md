## 💡 Giải thích SetID

| SetID Range | Loại |
|---|---|
| `100xx` | Set 3★ và 4★ cũ (Adventure, Brave Heart...) |
| `140xx` | Set 4★ nửa-5★ (Blizzard Strayer, Thundersoother...) |
| `150xx` | Set 5★ đầy đủ (từ Gladiator's Finale trở đi) |

> **Tip khi thêm set mới:** SetID mới nhất hiện tại là `15046`. Set tiếp theo sẽ là `15047` hoặc cao hơn.
