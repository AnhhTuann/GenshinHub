## 💡 Giải thích cấu trúc tên file

```
UI_EquipIcon_[Type]_[Key].png
```

| Type | Loại vũ khí |
|---|---|
| `Sword` | Kiếm một tay |
| `Claymore` | Đại kiếm |
| `Pole` | Thương |
| `Bow` | Cung |
| `Catalyst` | Pháp khí |

> **Lưu ý:** Một số key như `Mori`, `Arakalari`, `Isikhulu`... được dùng cho **nhiều loại vũ khí** cùng lúc (mỗi type có thiết kế riêng).
