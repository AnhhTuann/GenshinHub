A fresh TypeScript build reproduced all 718 previously tracked JavaScript paths in `backend/dist`. CI, Docker, and the VPS runbook build the backend before starting it. Git now ignores that output. The existing build directory remained available to the running local service. The tracked TypeScript incremental cache was removed and is now ignored when regenerated.

The two old standalone auth probes used fixed fixture credentials and targeted port 3000. No references to them were found in repository source, workflows, or documentation. The database-backed auth suite covers the supported endpoints. The obsolete Google OAuth configuration entry and the unused `@react-oauth/google` and `google-auth-library` dependencies were removed. npm updated the lockfile, retained dependency versions stayed the same, and a clean-directory `npm ci --dry-run` accepted the result.

Thirty-five Webpack cache files from three historical QA copies were deleted. The copies' sources, non-Webpack artifacts, and historical evidence remain available. Allocated blocks measured before unlinking totalled **938,762,240 bytes (895.27 MiB)** across the removed, singly linked files. This figure excludes compiled backend files retained on disk and does not subtract workspace output regenerated by verification builds.

The four local source-derived character reports remain untracked. Database backups, external evidence, migration history, restoration tools, canonical docs, and persistent WebP assets were preserved. The ignore additions cover the backend output, TypeScript build metadata, and root-level backend dump formats. The existing environment template exceptions remain in effect.
